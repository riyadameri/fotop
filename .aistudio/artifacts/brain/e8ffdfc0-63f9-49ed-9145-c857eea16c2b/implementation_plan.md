# نظام تنبيهات المخزون المنخفض وضبط إطار عرض الهواتف والجداول

تطوير نظام تنبيهات تفاعلي وبارز في لوحة التحكم (Dashboard) يعرض المواد والسلع التي انخفض مخزونها عن الحد الأدنى مع إمكانية الانتقال الفوري لتبويب المخزن، بالإضافة إلى ضبط وتثبيت إطار عرض شاشات الهواتف لمنع التكبير والتصغير العرضي، وتنسيق الجداول بأسلوب مضغوط وأنيق مخصص للهواتف.

---

## مراجعة المستخدم والقرارات المعتمدة

> [!IMPORTANT]
> تم أخذ تفضيلاتكم بعين الاعتبار:
> 1. **طريقة عرض الجداول على الهواتف**: اعتماد أسلوب العرض المصغر والمضغوط للأرقام والمعاملات مع إمكانية النقر على أي صف لفتح بطاقة تفاصيل شاملة وسلسة دون أي تشوه أو خروج عن الإطار.
> 2. **مكان تنبيهات المخزون المنخفض**: إضافة لوحة تنبيهية بارزة وتفاعلية في الجزء العلوي من لوحة التحكم أسفل المؤشرات القيادية مباشرة، تعرض المواد ذات المخزون الحرج أو المنفذ، مع زر وصول سريع للمخزن.

---

## 1. نظرة عامة والهدف الأساسي

- **ماذا يقدم التحديث**:
  - لوحة تحكم ذكية ترصد فورياً أي نقص في المواد الخام (أوراق، أحبار، إطارات) أو منتجات البيع المباشر، وتظهر تنبيهاً لافتاً بعدد المواد الحرجة وقائمتها بالتفصيل.
  - إمكانية النقر المباشر على أي مادة أو بطاقة التنبيه للانتقال الفوري إلى صفحة "المخزن والمواد" (`inventory`) مع تمييز المادة المطلوبة لإعادة التموين بسرعة.
  - حل جذري لمشكلة التكبير والتصغير (Zoom in/out) على شاشات الهواتف، وتثبيت عرض الصفحة بدقة 100% مع منع التمرير الأفقي الشاذ.
  - تحسين عرض الجداول المالية وقوائم الطلبات والمصروفات على شاشات الهواتف بنمط مضغوط ذكي (Compact View) يُسهّل القراءة بيد واحدة مع لوحة منبثقة للتفاصيل الكاملة عند النقر.

---

## 2. تجربة المستخدم والتصميم البصري

### أ. لوحة تنبيهات المخزون المنخفض في لوحة التحكم (Dashboard)
- **شريط تنبيه ذكي وتفاعلي**: يظهر تلقائياً عندما تكون هناك مواد مخزونها $\le$ الحد الأدنى (`minThreshold`).
- **تفاصيل بطاقة المادة**:
  - اسم المادة أو السلعة ونوعها (ورق، حبر، كادر، سلعة مباشرة).
  - مؤشر كمية ملون: أحمر قاني للمواد التي نفدت تماماً (0)، وبرتقالي دافئ للمواد التي انخفضت عن الحد الأدنى.
  - شريط تقدم بصري يوضح النسبة المتبقية من المخزون مقارنة بالحد الأدنى.
  - زر إجراء سريع "إعادة التموين في المخزن ↵" ينقل المشرف أو العامل فوراً لتبويب المخزن.
- **حالة الأمان الكامل**: إذا كانت جميع المواد متوفرة والمخزون أعلى من الحد الأدنى، يُعرض مؤشر طمأنينة أخضر أنيق ("المخزون متوازن وكافٍ - لا توجد نواقص").

### ب. تثبيت إطار العرض (Mobile Viewport Lockdown)
- **منع الزوم غير المرغوب**:
  - تحديث معلمات الـ Viewport في `index.html` لمنع التكبير التلقائي أو العرضي عند النقر المزدوج أو الكتابة.
  - ضبط حجم الخط في حقول الإدخال على الهواتف إلى $16\text{px}$ لمنع متصفحات الهواتف (خاصة Safari iOS) من عمل تكبير تلقائي عند التركيز على الحقول.
  - تطبيق خاصية `touch-action: pan-x pan-y;` و `touch-action: manipulation;` لمنع إيماءات التكبير غير المقصودة مع الحفاظ على مرونة التمرير.
  - منع الانفجار الأفقي للصفحة (`overflow-x: hidden; max-width: 100vw;`) وحصر أي جداول واسعة داخل حاويات تمرير أفقية معزولة وسلسة.

### ج. تنسيق الجداول على شاشات الهواتف
- **نمط العرض المضغوط (Compact Numbers & Click-for-Details)**:
  - على الشاشات الكبيرة: بقاء الجداول كاملة الأعمدة مع تنسيق خطي وأرقام جدولية (`tabular-nums font-mono`).
  - على الهواتف الذكية: تحويل أو تهيئة صفوف الجداول لتكون مضغوطة تركز على البيانات الجوهرية (المبلغ الإجمالي، التوقيت، واسم الزبون/الخدمة) بحجم خط منسق ومقروء.
  - إضافة زر/بطاقة نقر سريعة تفتح نافذة تفاصيل منسدلة (Quick Detail Sheet) لعرض كافة البنود والضرائب وتفاصيل المواد المستهلكة (BOM) بوضوح تام دون الحاجة لتكبير الشاشة.

## 3. القرارات التقنية ومعمارية الحل

### القرار 1: هيكلة تنبيهات المخزون في `DashboardView.tsx`
- **المنهج**: استخلاص قائمة المواد الحرجة `criticalMaterials` والسلع منخفضة المخزون، وعرضها في مكوّن `LowStockAlertBanner` أعلى قسم المؤشرات السريعة.
- **السبب**: وضع التنبيه في قمة اهتمام المدير أو العامل عند فتح لوحة القيادة، لسرعة التصرف قبل نفاذ أوراق التصوير أو الأحبار أثناء العمل.

### القرار 2: تثبيت Viewport وحل مشكلة الـ Zoom
- **المنهج**:
  1. تعديل وسَم الميتا في `index.html`:
     ```html
     <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover" />
     ```
  2. إضافة قواعد CSS في `src/index.css` لإلزام الحقول بالخط الآمن على الشاشات الصغيرة ومنع تجاوز العرض:
     ```css
     html, body {
       overflow-x: hidden;
       max-width: 100vw;
       touch-action: pan-x pan-y;
       -webkit-text-size-adjust: 100%;
     }
     button, input, select, textarea, a {
       touch-action: manipulation;
     }
     @media screen and (max-width: 768px) {
       input, select, textarea {
         font-size: 16px !important;
       }
     }
     ```
- **السبب**: حل المشكلة نهائياً في كافة متصفحات الهواتف (Chrome Android و iOS Safari).

### القرار 3: تجاوب الجداول (Responsive Tables)
- **المنهج**: تغليف الجداول في حاويات `w-full overflow-x-auto touch-pan-x`، مع توفير وضع مدمج مخصص للهواتف يعرض البيانات بطريقة مقتضبة ونقر للحصول على التفاصيل.

## 5. حالة التنفيذ والتحقق

- [x] **تحديث `index.html` و `src/index.css`**:
  - تم تثبيت إطار العرض `viewport` مع `user-scalable=no, maximum-scale=1.0, viewport-fit=cover`.
  - تم تطبيق قواعد منع التكبير والتصغير والارتجاج الأفقي: `touch-action: pan-x pan-y`, `text-size-adjust: 100%`, `font-size: 16px !important` للمدخلات على الهواتف.
  - تم إضافة حماية عامة للجداول وحاويات التمرير `.overflow-x-auto, .table-responsive-container` لمنع تمدد الشاشة.
- [x] **تطوير نظام تنبيهات المخزون في لوحة التحكم (`DashboardView.tsx`)**:
  - لوحة تنبيهات ذكية وبارزة تعرض قائمة المواد تحت الحد الأدنى مع شارات الحالة (نفذ بالكامل، حرج جداً، تحت الحد).
  - تصنيف المواد وعرض المقاييس الدقيقة: المخزون الحالي، الحد الأدنى، العجز المطلوب، تكلفة التوريد المقدرة، وشريط التقدم الملون.
  - إمكانية التصفية السريعة (الكل، نفذ بالكامل، حرج، تحت الحد).
  - ربط النقر على أي بطاقة بالانتقال المباشر للمخزن (`onNavigateToInventory` و `onNavigateTab('inventory')`) مع تمرير الفلتر واسم المادة.
  - حالة طمأنينة خضراء أنيقة عند اكتمال المخزون بنسبة 100%.
- [x] **تنسيق الجداول والعرض المضغوط للهواتف**:
  - على الهواتف: عرض بطاقات مقتضبة ومضغوطة للأرقام والحالات (`sm:hidden`).
  - عند النقر على أي معاملة: فتح نافذة تفاصيل شاملة (Order Details Modal) تعرض البنود والكميات وطريقة الدفع دون الحاجة للتكبير.
  - على الشاشات الكبيرة: جدول متجاوب وأنيق مع حاوية تمرير محكومة.
- [x] **التحقق والاختبار**:
  - نجاح بناء التطبيق وتجميعه (`compile_applet`).
  - اجتياز الفحص البرمجي بدون أي أخطاء (`tsc --noEmit`).
  - إعادة تشغيل خادم التطوير بنجاح.
